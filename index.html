VuIO Media Server

Official Linux Package Repositories & Direct Downloads

Ubuntu / Debian (APT Repository) Debian, Ubuntu, Mint, Pop!_OS

Add the official APT repository to get automatic updates:

echo "deb [trusted=yes] https://vuiodev.github.io/vuio/apt stable main" | sudo tee /etc/apt/sources.list.d/vuio.list
sudo apt update
sudo apt install vuio

Or download direct .deb packages:

Download .deb (x86_64) Download .deb (ARM64)

Fedora / RHEL / CentOS (RPM Repository) Fedora, RHEL, CentOS, Rocky, Alma

Add the official DNF / YUM repository:

sudo dnf config-manager --add-repo https://vuiodev.github.io/vuio/rpm/vuio.repo
sudo dnf install vuio

Or download direct .rpm packages:

Download .rpm (x86_64) Download .rpm (ARM64)

Arch Linux (Pacman Repository) Arch Linux / Manjaro

Add the official Arch Linux repository to /etc/pacman.conf:

[vuio]
SigLevel = Optional TrustAll
Server = https://vuiodev.github.io/vuio/arch/os/$arch

# Then update pacman and install:
sudo pacman -Sy vuio

Or download direct .pkg.tar.zst packages:

Download .pkg.tar.zst (x86_64) Download .pkg.tar.zst (ARM64)

Alpine Linux (APK Repository) Alpine Linux / APK

Add the official Alpine APK repository to /etc/apk/repositories:

echo "https://vuiodev.github.io/vuio/alpine/stable/main" | sudo tee -a /etc/apk/repositories
sudo apk update
sudo apk add --allow-untrusted vuio

Or download direct .apk packages:

Download .apk (x86_64) Download .apk (ARM64)

Docker Multi-Architecture Image Docker / Podman

Run the official container from GitHub Container Registry (supports x86_64 and ARM64):

docker run -d \
  --name vuio-server \
  --restart unless-stopped \
  --network host \
  -v /path/to/media:/media:ro \
  -v ./vuio-config:/config \
  ghcr.io/vuiodev/vuio:latest

Homebrew (macOS & Linux) Brew

brew tap vuiodev/vuio
brew install vuio
